Reliable reminders

Checking reminder connection…

Brain Dump, tasks and unscheduled Memory Inbox items stay in this browser. When reliable reminders are connected, reminder text is encrypted on this device before cloud sync. The reminder service still processes delivery time, recurrence, timezone and technical push metadata so notifications can arrive.

Privacy & cloud data

Cuenora's reminder service should not need to read the private words in your reminders. If the local encryption key is unavailable, a due notification still arrives with a generic private-reminder message.
